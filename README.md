# مِهنتي — منصة توظيف مستقلة

واجهة أولية عربية RTL للعمال وأصحاب الأفران والمخابز والمطاعم.

## التشغيل
- Node.js 20+
- نفّذ: `npm install`
- ثم: `npm run dev`
- للبناء: `npm run build`

## المزايا الموجودة في النموذج
- حساب عامل أو حساب تجاري (فرن/مخبز/مطعم).
- اختيار التخصص بالضغط على الاسم، مع قائمة وظائف المطاعم الموسعة.
- نشر الوظائف وحجز العامل للوظيفة.
- محادثة تجريبية وتعليمات تحويل يدوي خارج التطبيق.
- موافقة مستقلة من العامل وصاحب العمل، أو إلغاء الحجز.
- تخزين محلي في المتصفح فقط.

## تنبيه مهم
هذه نسخة واجهة تجريبية وليست منصة إنتاجية متعددة المستخدمين. التسجيل والحجوزات والدردشة تحفظ محلياً في المتصفح ولا تتزامن بين الأجهزة. لا تستخدم بيانات هوية حقيقية في هذه النسخة.

## Supabase
ملف `supabase/schema.sql` مخطط أولي للمراجعة فقط. يلزم ربط Supabase Auth فعلياً، واستكمال سياسات RLS، وكتابة عمليات RPC ذرية للحجز والموافقة والإلغاء قبل الاستخدام الحقيقي.

## الدفع والخصوصية
لا توجد محفظة أو بوابة دفع داخل التطبيق. التحويل المذكور يدوي وخارج التطبيق، ولا يتم التحقق منه. رقم البطاقة الوطنية بيانات حساسة؛ يجب تقليل جمعه وتشفيره ومنع عرضه للعامة قبل الإطلاق.

## الخرائط وTelegram
لم يتم تفعيل الخرائط أو تتبع الوصول أو إشعارات Telegram بعد. أي Telegram bot token يجب حفظه في أسرار خادمية، وليس داخل ملفات الواجهة أو متغيرات VITE.
