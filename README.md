# مهنتي الحُرّة — نسخة جديدة
تم استبدال محتويات التطبيق القديمة بنسخة تأسيسية جديدة للهاتف.

## الوظائف
العامل يتصفح الوظائف ويتقدم لها. صاحب العمل ينشر الوظائف.

## سوق المشاريع
إضافة مشاريع للبيع مع التصنيف والسعر والموقع والصورة ورقم التواصل.

## الفيديو
رفع مقاطع مهنية وإعجابات فقط. لا توجد تعليقات.

## إعداد Supabase
1. أنشئ مشروع Supabase.
2. افتح SQL Editor وشغّل الملف `supabase/schema.sql`.
3. انسخ `config.example.js` إلى `config.js`، وأدخل Project URL و anon/publishable key.
4. أضف إلى index.html قبل كود التطبيق: `<script src="config.js"></script>`.
5. لا تضع service_role key في تطبيق الهاتف أو GitHub.
6. فعّل تأكيد البريد أو عطّله حسب سياسة الإطلاق.

## AppsGeyser
يمكن استخدام index.html كنقطة دخول HTML. AppsGeyser يجب أن يستطيع تحميل الإنترنت للوصول إلى Supabase وملفات CDN.

## ملاحظات
- قاعدة البيانات لا تنشأ بمجرد رفع ملفات SQL؛ يجب تنفيذ schema.sql في مشروع Supabase.
- اختبر التسجيل والرفع وRLS قبل الإطلاق العام.
