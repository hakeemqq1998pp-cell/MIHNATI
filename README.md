# مِهنتي — منصة توظيف مستقلة

تطبيق عربي RTL للربط بين العمال وأصحاب الأفران والمخابز والمطاعم.

## التقنية
- React + Vite
- Supabase Auth + PostgreSQL + Row Level Security + Realtime
- Netlify للنشر

## تشغيل محلي
1. ثبّت Node.js 20 أو أحدث.
2. نفّذ `npm install`.
3. انسخ `.env.example` إلى `.env`.
4. أدخل عنوان مشروع Supabase ومفتاح anon/public في متغيرات البيئة.
5. نفّذ `npm run dev`، وللبناء `npm run build`.

## إعداد Supabase
1. أنشئ مشروعاً في Supabase.
2. افتح SQL Editor وشغّل `supabase/schema.sql` أولاً.
3. شغّل بعدها `supabase/migrations/20261108_secure_backend.sql`.
4. من Authentication > Providers تأكد من تفعيل Email.
5. عند تفعيل تأكيد البريد، يجب على المستخدم تأكيد بريده ثم تسجيل الدخول؛ بيانات الملف الشخصي تُنشأ من بيانات التسجيل المحفوظة في Auth metadata.

## إعداد Netlify
1. اربط المستودع `hakeemqq1998pp-cell/MIHNATI` بموقع Netlify.
2. إعداد البناء: `npm run build` ومجلد النشر `dist` (موجود أيضاً في netlify.toml).
3. أضف متغيري البيئة:
   - `VITE_SUPABASE_URL`
   - `VITE_SUPABASE_ANON_KEY`
4. أعد النشر بعد إضافة المتغيرات.

استخدم مفتاح Supabase anon/public فقط في الواجهة. لا تضع service_role أو مفاتيح Telegram أو أي سر خادمي في متغير يبدأ بـ VITE_.

## الوظائف الحالية
- إنشاء حساب عامل أو حساب تجاري عبر البريد وكلمة المرور.
- نشر وظائف الأفران والمخابز والمطاعم واختيار التخصص من قائمة.
- حجز ذري من خلال RPC يمنع حجز الوظيفة النشطة من أكثر من عامل.
- دردشة مخزنة في قاعدة البيانات مع تحديثات Realtime.
- موافقة منفصلة من العامل وصاحب العمل؛ لا يتم اعتماد الاتفاق إلا بعد موافقتهما.
- إلغاء الحجز يعيد الوظيفة إلى الحالة المتاحة.
- لا توجد محفظة أو بوابة دفع. التحويل المذكور في الدردشة يدوي وخارج التطبيق.

## الحالة والقيود
هذا إصدار تأسيسي يحتاج اختباراً عملياً على مشروع Supabase وNetlify قبل إطلاقه للعامة. الخرائط، تحديد الموقع الفعلي، مسارات الوصول، إشعارات Telegram، لوحة الإدارة، التحقق من الحسابات، واسترجاع كلمة المرور بواجهة مخصصة لم تُنجز بعد.

لا تدخل أرقام البطاقة الوطنية أو صور المستندات في هذه النسخة. عمود national_id القديم في المخطط لا تمنح الواجهة صلاحية قراءته أو كتابته في migration الحالية. يجب تنفيذ تدفق تحقق آمن ومشفّر ومراجعة سياسات الوصول قبل جمع أي مستندات.

رسوم التحويل (3000 دينار لكل طرف) مجرد تعليمات نصية، ولا يستلم التطبيق الأموال ولا يتحقق من التحويل.
